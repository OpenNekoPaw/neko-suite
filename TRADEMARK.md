# Neko Suite Trademark Policy

## Purpose

The open source license governing Neko Suite's code (GNU Affero General
Public License v3.0 or later) grants broad permissions to use, modify, and
distribute the software. However, this license does **not** grant permission to use the
Neko Suite trademarks. This policy explains how you may — and may not —
use our brand.

## Protected Marks

The following names and marks are trademarks of the Neko Suite project:

- **Neko Suite** (the project name)
- **neko-cut**, **neko-agent**, **neko-canvas**, **neko-story**,
  **neko-sketch**, **neko-model**, **neko-audio**, **neko-preview**,
  **neko-market**, **neko-tools**, **neko-live**, **neko-assets**,
  **neko-engine** (module names)
- The Neko Suite logo and associated artwork
- The **nk*** file format identifiers (`.nkv`, `.nkc`, `.nks`, `.nkm`)

## Permitted Uses (No approval needed)

You **may** use the Neko Suite marks without prior approval in the
following cases:

### Descriptive Reference

Referring to the project by name in documentation, articles, blog posts,
talks, and academic work:

> "Our product is built on Neko Suite's open source engine."
> "This plugin is compatible with neko-cut."

### Unmodified Distribution

Distributing verbatim, unmodified copies of the official Neko Suite
software, including the original marks and branding.

### Community Projects

Using the marks in community contexts that clearly indicate unofficial
status:

> "Neko Suite Community Forum"
> "Unofficial Neko Suite Plugins"

## Restricted Uses (Approval required)

You **must** obtain written permission before:

- Using "Neko" or "Neko Suite" as part of your product name, company name,
  or domain name (e.g., "NekoEditor", "neko-pro.com").
- Using the Neko Suite logo or artwork in your product's UI, marketing
  materials, or app store listings.
- Creating merchandise bearing the Neko Suite marks.

## Prohibited Uses

You **may not**, under any circumstances:

- **Imply official endorsement**: Use the marks in a way that suggests your
  product is officially part of, endorsed by, or affiliated with the Neko
  Suite project when it is not.
- **Create confusion**: Use names or logos confusingly similar to Neko Suite
  marks for derivative or competing products.
- **Disparage the brand**: Use the marks in connection with malicious
  software, deceptive practices, or abusive content.

## Derivative Works / Forks

If you create a fork or derivative product:

- **Remove Neko Suite branding**: Replace the name, logo, and any marks
  with your own branding. This makes it clear that your product is
  independent.
- **Credit the origin**: Include a notice such as: "Based on Neko Suite
  (https://github.com/aspect-apps/neko-suite), licensed under the GNU
  Affero General Public License v3.0 or later."
- **Do not use neko-* prefixes**: Choose a distinct name for your modules
  (e.g., "myapp-cut" instead of "neko-cut").

### Example of compliant fork branding

```
✅ "VideoForge — a video editor based on Neko Suite"
✅ "Powered by Neko Suite open source technology"
❌ "Neko Suite Pro"
❌ "Neko Cut Enhanced Edition"
```

## Requesting Permission

To request permission for restricted uses, open an issue in the main
repository with the `trademark` label, or contact the maintainers directly.
Include:

- Your intended use
- Mockups or screenshots if applicable
- How you will make the unofficial nature clear

## Enforcement

We enforce this policy to protect both the project and its users. Violations
may result in:

- A request to cease the infringing use
- Reporting to relevant platforms (VS Code Marketplace, GitHub, npm)
- Legal action if necessary
