# TUI I18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add VSCode-free internationalization to the Neko Agent TUI while separating terminal UI language from Agent prompt language.

**Architecture:** Reuse the existing Layer 0 `@neko/shared` i18n primitives for translation and locale normalization, but keep TUI locale detection in `cli-tui` because TUI runs in Node and cannot read VSCode `vscode.env.language` or Webview DOM attributes. Persist locale configuration as `LocaleMode` intent (`auto | en | zh-cn`) and expose resolved runtime locales separately. `uiLocale` controls terminal text, `promptLocale` controls built-in prompt and Skill assets, and model response language continues to follow the user's current message or explicit instruction.

**Tech Stack:** TypeScript, React Ink, Zustand, Commander, Vitest, `@neko/shared` i18n, existing Neko TOML config reader, existing `@neko/agent` prompt builder and Skill catalog.

---

## Scope

This plan implements TUI locale infrastructure and localizes the surfaces that define the interactive shell: startup banner, status bar labels, config/model/locale command output, command errors, model picker titles, and Agent prompt/Skill locale wiring.

This plan does not change Webview i18n. Webview already reads `data-vscode-locale` from Extension-generated HTML and registers en/zh-cn bundles through `@neko/shared/i18n/webview`.

This plan does not add a persistent `responseLanguage` setting. Response language is a conversation policy: explicit user instruction wins, then current-message language, then recent conversation language, with `promptLocale` only acting as a weak default for built-in prompt assets.

```ts
import type { SupportedLocale } from '@neko/shared';

export type TuiLocaleMode = SupportedLocale | 'auto';

export interface TuiLocaleResolutionInput {
  readonly cliLocale?: unknown;
  readonly cliUiLocale?: unknown;
  readonly cliPromptLocale?: unknown;
  readonly userUiLocale?: unknown;
  readonly userPromptLocale?: unknown;
  readonly workspacePromptLocale?: unknown;
  readonly env?: NodeJS.ProcessEnv;
}

export interface TuiLocaleResolution {
  readonly detectedLocale: SupportedLocale;
  readonly uiLocaleMode: TuiLocaleMode;
  readonly promptLocaleMode: TuiLocaleMode;
  readonly uiLocale: SupportedLocale;
  readonly promptLocale: SupportedLocale;
}

const SUPPORTED_LOCALE_MODES: readonly TuiLocaleMode[] = ['auto', 'en', 'zh-cn'];

export function validateTuiLocaleMode(value: unknown, label: string): TuiLocaleMode | undefined {
  if (value === undefined) return undefined;
  if (typeof value !== 'string') {
    throw new Error(`${label} must be one of: auto, en, zh-cn.`);
  }
  const normalized = value.trim().toLowerCase().replace(/_/g, '-');
  if (normalized === 'auto') return 'auto';
  const locale = parseSupportedLocale(normalized);
  if (locale) return locale;
  throw new Error(`${label} must be one of: auto, en, zh-cn.`);
}

export function detectTuiLocaleFromEnv(env: NodeJS.ProcessEnv = process.env): SupportedLocale {
  const raw =
    readFirstLocaleToken(env['NEKO_LOCALE']) ??
    readFirstLocaleToken(env['LC_ALL']) ??
    readFirstLocaleToken(env['LC_MESSAGES']) ??
    readFirstLocaleToken(env['LANGUAGE']) ??
    readFirstLocaleToken(env['LANG']);
  return parseSupportedLocale(raw) ?? 'en';
}

export function resolveTuiLocales(input: TuiLocaleResolutionInput = {}): TuiLocaleResolution {
  const detectedLocale = detectTuiLocaleFromEnv(input.env);
  const cliLocale = validateTuiLocaleMode(input.cliLocale, '--locale');
  const cliUiLocale = validateTuiLocaleMode(input.cliUiLocale, '--ui-locale');
  const cliPromptLocale = validateTuiLocaleMode(input.cliPromptLocale, '--prompt-locale');
  const userUiLocale = validateTuiLocaleMode(input.userUiLocale, 'uiLocale');
  const userPromptLocale = validateTuiLocaleMode(input.userPromptLocale, 'promptLocale');
  const workspacePromptLocale = validateTuiLocaleMode(
    input.workspacePromptLocale,
    'workspace promptLocale',
  );

  const uiLocaleMode = cliUiLocale ?? cliLocale ?? userUiLocale ?? 'auto';
  const promptLocaleMode =
    cliPromptLocale ?? cliLocale ?? workspacePromptLocale ?? userPromptLocale ?? uiLocaleMode;
  const uiLocale = resolveUiLocaleMode(uiLocaleMode, detectedLocale);
  const promptLocale = resolvePromptLocaleMode(promptLocaleMode, uiLocale);

  return {
    detectedLocale,
    uiLocaleMode,
    promptLocaleMode,
    uiLocale,
    promptLocale,
  };
}

export function toAgentPromptLocale(locale: SupportedLocale): 'en' | 'zh' {
  return locale === 'zh-cn' ? 'zh' : 'en';
}

function resolveUiLocaleMode(
  mode: TuiLocaleMode,
  detectedLocale: SupportedLocale,
): SupportedLocale {
  return mode === 'auto' ? detectedLocale : mode;
}

function resolvePromptLocaleMode(mode: TuiLocaleMode, uiLocale: SupportedLocale): SupportedLocale {
  return mode === 'auto' ? uiLocale : mode;
}

function readFirstLocaleToken(value: string | undefined): string | undefined {
  const trimmed = value?.trim();
  if (!trimmed) return undefined;
  return trimmed.split(':')[0]?.split('.')[0]?.replace(/_/g, '-');
}

function parseSupportedLocale(value: string | undefined): SupportedLocale | undefined {
  const normalized = value?.trim().toLowerCase().replace(/_/g, '-');
  if (!normalized) return undefined;
  if (normalized === 'en' || normalized.startsWith('en-')) return 'en';
  if (
    normalized === 'zh' ||
    normalized === 'zh-cn' ||
    normalized.startsWith('zh-hans') ||
    normalized.startsWith('zh-cn-')
  ) {
    return 'zh-cn';
  }
  return undefined;
}
```

```ts
import { I18nService, type SupportedLocale } from '@neko/shared';
import { en } from './locales/en';
import { zhCn } from './locales/zh-cn';

const NAMESPACE = 'agent-tui';

export function createTuiI18n(locale: SupportedLocale): I18nService {
  const service = new I18nService(locale, 'en');
  service.registerBundle(NAMESPACE, 'en', en);
  service.registerBundle(NAMESPACE, 'zh-cn', zhCn);
  return service;
}

export function translateTui(
  locale: SupportedLocale,
  key: string,

function handleLocale(args: string[], context: SlashCommandContext): SlashCommandResult {
  const t = (key: string, params?: Record<string, string | number>) =>
    translateTui(context.config.uiLocale, key, params);
  const subcommand = args[0]?.toLowerCase();

  if (!subcommand || subcommand === 'status') {
    return {
      handled: true,
      continueExecution: true,
      output: t('locale.status', {
        ui: context.config.uiLocale,
        uiMode: context.config.uiLocaleMode,
        prompt: context.config.promptLocale,
        promptMode: context.config.promptLocaleMode,
      }),
    };
  }

  if (subcommand === 'ui' || subcommand === 'prompt') {
    const locale = readLocaleCommandValue(args[1], subcommand, t);
    if (!locale) {
      return { handled: true, continueExecution: true, error: t('locale.usage') };
    }
    if (subcommand === 'ui') {
      context.onConfigUpdate?.(
        resolveRuntimeLocaleUpdate({
          uiLocaleMode: locale,
          promptLocaleMode: context.config.promptLocaleMode,
        }),
      );
      return {
        handled: true,
        continueExecution: true,
        output: t('locale.updatedUi', { locale }),
      };
    }
    context.onConfigUpdate?.({
      ...resolveRuntimeLocaleUpdate({
        uiLocaleMode: context.config.uiLocaleMode,
        promptLocaleMode: locale,
      }),
    });
    return {
      handled: true,
      continueExecution: true,
      output: t('locale.updatedPrompt', { locale }),
    };
  }

  const locale = readLocaleCommandValue(subcommand, 'locale', t);
  if (!locale) {
    return { handled: true, continueExecution: true, error: t('locale.usage') };
  }
  context.onConfigUpdate?.(
    resolveRuntimeLocaleUpdate({
      uiLocaleMode: locale,
      promptLocaleMode: locale,
    }),
  );
  return {
    handled: true,
    continueExecution: true,
    output: t('locale.updatedBoth', { locale }),
  };
}

function readLocaleCommandValue(
  raw: string | undefined,
  label: string,
  t: (key: string, params?: Record<string, string | number>) => string,
): TuiLocaleMode | null {
  try {
    return validateTuiLocaleMode(raw, label) ?? null;
  } catch {
    throw new Error(t('error.invalidLocale', { label }));
  }
}

function resolveRuntimeLocaleUpdate(input: {
  readonly uiLocaleMode: TuiLocaleMode;
  readonly promptLocaleMode: TuiLocaleMode;
}): Pick<
  CLIConfig,
  'detectedLocale' | 'uiLocaleMode' | 'uiLocale' | 'promptLocaleMode' | 'promptLocale'
> {
  const resolved = resolveTuiLocales({
    cliUiLocale: input.uiLocaleMode,
    cliPromptLocale: input.promptLocaleMode,
  });
  return {
    detectedLocale: resolved.detectedLocale,
    uiLocaleMode: resolved.uiLocaleMode,
    uiLocale: resolved.uiLocale,
    promptLocaleMode: resolved.promptLocaleMode,
    promptLocale: resolved.promptLocale,
  };
}
```

````md
# Neko Agent TUI

## Locale

The TUI separates terminal interface language from Agent prompt language.

- `uiLocale` controls terminal UI strings such as command output, status labels, and startup text.
- `promptLocale` controls Agent system prompt language, built-in Skill locale, and runtime prompt metadata.
- Model response language is not a persistent locale setting. It follows explicit user instruction first, then the current message language, then recent conversation language.

CLI options:

```bash
neko --locale zh-cn
neko --ui-locale zh-cn --prompt-locale en
neko config show --ui-locale zh-cn
```

User config keys in `~/.neko/config.toml`:

```toml
ui_locale = "auto"
prompt_locale = "zh-cn"
```

Workspace config may set project prompt assets in `<workDir>/.neko/config.toml`:

```toml
prompt_locale = "zh-cn"
```

The TUI intentionally ignores workspace `ui_locale` so a project cannot silently change a user's terminal UI language. Workspace `prompt_locale` may override user `prompt_locale` because creative projects sometimes need consistent prompt/Skill asset language.

Accepted values:

- `auto`
- `en`
- `zh-cn`

UI locale resolution order:

1. CLI options
2. User config
3. Terminal environment: `NEKO_LOCALE`, `LC_ALL`, `LC_MESSAGES`, `LANGUAGE`, `LANG`
4. English

Prompt locale resolution order:

1. CLI options
2. Workspace config
3. User config
4. Resolved UI locale

When `promptLocale` is omitted or set to `auto`, it follows the resolved `uiLocale`.

Runtime command:

```text
/locale status
/locale zh-cn
/locale ui en
/locale prompt zh-cn
```

`/locale` changes the current TUI session. A later `/locale save` command can be added if persistent mutation is needed, but this plan keeps the first implementation session-only.
````
