## 当前工作目录的作用

在本轮任务里，当前工作目录主要是**共享工作区的默认上下文**，用于代码类协作时定位项目文件、解析相对路径、执行检查或修改代码。

但就你这条请求而言：

| 事项 | 当前工作目录的作用 |
|---|---|
| 说明规则/上下文 | 只作为环境背景，不需要读取文件 |
| 创作文档 Draft / Plan / Task | **不能**通过当前目录或文件路径自行读取、写入、修复 |
| 文件内容判断 | 不能凭工作目录推断，必须实际读取后才能说明 |
| 相对路径写入 | 若后续明确要求改文件，工具会按工作区根目录解析相对路径 |
| 隐藏 runtime/cache 路径 | 不能当作有效创作文档表面使用 |

所以，本轮我不会根据“当前工作目录”编造任何项目文件内容。它只表示我们共享的工程环境；只有当你要求检查或修改具体代码文件时，我才会通过可用工具读取对应文件后再作判断。
