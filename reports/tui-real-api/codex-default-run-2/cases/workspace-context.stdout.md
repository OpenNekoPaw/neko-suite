## 当前工作目录的作用

当前工作目录主要是**工具解析相对路径的基准位置**，也就是当我使用文件工具并传入相对路径时，系统会按工作区根目录来解析它。

在本轮任务里，你只是要求我说明它的作用，并且要求不要编造文件内容。因此我不会假设当前目录里有哪些文件，也不会引用未读取过的文件内容。

### 具体影响

| 场景 | 当前工作目录的作用 |
|---|---|
| 读取文件 | 如果使用相对路径，路径会相对于工作区根目录解析 |
| 写入文件 | 如果明确允许写入， relative path 会写到工作区根目录下对应位置 |
| 列目录 / 搜索 | 需要基于已知路径执行；不能凭空假设目录内容 |
| 创作文档 Draft / Plan / Task | 不应通过普通文件读写或隐藏 runtime/cache 路径处理，需遵守宿主 creation-document 服务规则 |
| 本轮回答 | 只说明机制，不读取、不推断、不编造当前目录文件内容 |

### 结论

当前工作目录在本轮任务中只是一个**路径解析上下文**。由于你没有要求我检查目录内容，我也没有读取任何文件，所以不能也不会声称当前目录包含什么项目文件或具体内容。
