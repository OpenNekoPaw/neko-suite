# Neko Suite Domain Context

This file records shared domain language that is useful across implementation, tests, and architecture discussions. It is intentionally concise: terms are added when they become load-bearing for design decisions.

## Agent Turn And Continuation

### Agent Turn

One execution pass of the main Agent over a prompt-like input. A turn may stream assistant text, call tools, submit background tasks, and finish before those background tasks complete.

### User Message

A prompt authored by the user through the TUI composer or an explicit user-facing command. User messages may enter the pending message queue while the Agent is busy, but they become transcript messages only when released for execution.

### Internal Continuation

A prompt-like instruction generated by the runtime, not authored by the user, to let the Agent consume a completed background result or subagent result. Internal continuations may be delivered to the model as turn input, but must not be displayed or recorded as user messages.

### Task Result Observation

A durable record that a background task reached a terminal state and produced result evidence, such as generated media resource references or a failure diagnostic. Task result observations are the canonical input for task-result continuations.

### Message Queue

The queue of user-authored prompts waiting for execution while the Agent is busy. It represents pending user intent and should not be reused for internal continuations without preserving source metadata.

### Continuation Queue

The queue of runtime-authored internal continuations waiting for the main Agent to become idle. It is ordered with the message queue by conversation policy, but keeps a distinct source and display contract.

### Task Group

A local grouping of related background tasks whose results should be consumed together or according to a declared policy, such as wait-all or continue-on-each.

### Immediate Send

A user action that asks the TUI to run a user-authored prompt ahead of pending internal continuations. It changes execution order but does not implicitly cancel the current turn or discard the continuation.

### Turn Interrupt

A user action that stops the currently running Agent turn. It is distinct from immediate send and from cancelling pending queued items.

### Continuation Discard

A user action or diagnostic decision that explicitly drops a pending internal continuation. Discarding a continuation should be visible in timeline, journal, or eval facts because it changes whether a background result is consumed by the main Agent.

### Subagent Sidechain

The execution history of a spawned subagent. The main conversation consumes subagent summaries and artifact references, not the raw sidechain transcript.
